Soy desarrollador web junior en formación. Armo aplicaciones de escritorio y páginas web con **Python, JavaScript, HTML y CSS**, trabajo con bases de datos **SQL** y versiono todo con **Git y GitHub**.

Vengo de trabajos operativos donde aprendí responsabilidad, trabajo en equipo y cumplimiento de plazos. Hoy dedico mi tiempo a programar y a publicar proyectos propios.

- 🎯 **Busco:** mi primera posición como Desarrollador Web Junior o Trainee
